Ce portfolio a été conçu pour présenter mon profil en tant que développeur web, mettre en avant mes compétences techniques et partager mes réalisations dans le domaine du développement digital.

Il met en valeur :

- mes compétences en développement Front-end et Back-end,
- mes projets réalisés,
- mes outils et technologies préférés,
- mon profil de recherche de stage.

## Démarrage local

1. Clonez le dépôt :
```bash
git clone https://github.com/adamettossain-dev/Portfolio.git
```

2. Accédez au dossier du projet :
```bash
cd Portfolio
```

3. Ouvrez le fichier `index.html` dans votre navigateur, ou utilisez un serveur local si vous préférez.

Exemple simple avec Python :
```bash
python -m http.server 8000
```

Puis ouvrez :
```text
http://localhost:8000
```
